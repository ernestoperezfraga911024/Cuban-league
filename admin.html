Instalar Cuban Admin

El acceso directo abrirá este panel privado como una aplicación independiente.

Primero abre el panel en Safari Si estás usando Chrome, ChatGPT o WhatsApp, copia el enlace y pégalo en Safari. En esos navegadores puede no aparecer la opción correcta.

  1. 1
    Abre SafariPega allí el enlace copiado del panel privado.
  2. 2
    Toca el botón Compartir de SafariEs el cuadrado con una flecha hacia arriba situado en la barra de Safari.
  3. 3
    Selecciona “Add to Home Screen”También puede aparecer como “Añadir a pantalla de inicio”.
  4. 4
    Confirma con “Add”En el iPhone aparecerá una aplicación llamada Cuban Admin.
